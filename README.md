# EcoHeat Plumbing and Renewables — website

Static marketing site for **Ecoheat Plumbing and Renewables Limited** (company
number 15532701, Gas Safe register 952210), covering Somerset and North
Somerset.

No framework, no build dependencies beyond Python 3, no JavaScript required to
read or navigate the site. 20 pages, ~60 KB of CSS and JS combined.

---

## Working on it

```sh
python3 build.py            # regenerate the site into the repository root
python3 build.py --check    # verify the committed HTML matches src/content.py
python3 -m http.server 8000 # preview at http://localhost:8000
```

**All content lives in [`src/content.py`](src/content.py).** Edit that file, not
the generated HTML — running the build overwrites every `.html` file. The
generator is [`build.py`](build.py); the stylesheet
[`assets/css/main.css`](assets/css/main.css) and
[`assets/js/site.js`](assets/js/site.js) are hand-written and are not generated.

Both the generated HTML and the generator are committed, so the site can be
served directly from the repository with no build step. `build.py --check` runs
in CI and fails if the two ever drift apart.

### What the build enforces

The build fails, and CI with it, on any of:

- a page with no `<h1>`, or more than one
- a skipped heading level (`h1` straight to `h3`)
- a duplicate `<title>` or duplicate meta description
- a title over 65 characters, or a meta description outside 110–175
- a broken internal link

## Before this goes live

Six things need a decision from EcoHeat. Each is marked `NEEDS SIGN-OFF` in the
source. The site is complete and publishable without them, but these are the
items where the code is deliberately not guessing on the business's behalf.

### 1. MCS accreditation — required before advertising heat pumps

`MCS_STATUS` in `src/content.py` is currently `"partner"`, which produces the
wording *"designed, commissioned and certified with our MCS-accredited
installation partner"* across the home page, heat pump page, grants page, About
page and FAQ.

**This must be true before launch.** The Boiler Upgrade Scheme grant is only
payable where the installer is MCS certified, so this claim is both a marketing
statement and a regulatory one.

- If EcoHeat now holds its own certificate: set `MCS_STATUS = "own"` and
  `MCS_NUMBER = "NAP-…"`, then rebuild. Every page updates, including a
  verifiable certificate number in the trust bar.
- If there is no partner arrangement in place: say so, and the heat pump and
  grants pages need rewriting before publication rather than adjusting.

### 2. Service plan prices

`PLANS` in `src/content.py` has `monthly` and `annual` set to `None` on all
three plans, so each card currently shows **"Call for price"** with the payment
intervals and full inclusions listed underneath. Nothing fictional is published.

Fill in the two numbers per plan and rebuild to publish real pricing. As a
starting point for that conversation, the going rate in the South West for
comparable cover is roughly:

| Plan | Monthly | Annual | Notes |
| --- | --- | --- | --- |
| Essential | £9–12 | £99–129 | Service only; annual price ≈ 11 monthly payments |
| Complete | £18–24 | £199–249 | Service plus breakdown labour |
| Renewables | £14–18 | £159–199 | Heat pump service, F-Gas check, cylinder G3 |

These are indicative market figures for benchmarking, not a recommendation —
price them against your own labour cost and expected call-out rate.

### 3. Contact form endpoint

`FORM_ENDPOINT` at the top of `build.py` is empty. The form therefore submits by
`mailto:`, opening the visitor's own email client. That works everywhere and
means no third party ever receives customer data — which is why the privacy
policy can state that plainly — but it is a worse conversion path on mobile.

To use a hosted form handler (Formspree, Netlify Forms, Basin, or a bespoke
endpoint), set `FORM_ENDPOINT` to the HTTPS URL and rebuild. The form then
submits inline via `fetch()` with a success message and no page reload.

**If you do that**, the privacy policy needs the processor named — the build
already leaves a marked paragraph in *"Who we share it with"* for exactly this.
That is a GDPR requirement, not an optional nicety.

### 4. Finance provider details

The finance page describes typical options generically. Once a lender is
appointed, add to `build_finance()` in `build.py`: the provider's name, their
FCA firm reference number, EcoHeat's own credit broker permission or exemption,
and a representative example. Consumer credit promotions must comply with FCA
CONC 3 — an APR quoted without a representative example is a breach.

### 5. Reviews

`REVIEWS` in `src/content.py` is an empty list, so the reviews page links to
Facebook instead of showing quotes. This is deliberate: no testimonials have
been invented, and no `AggregateRating` schema is emitted.

Publishing review markup for reviews that do not exist risks a Google manual
action and, since the DMCC Act 2024, is a CMA enforcement matter. Add genuine
reviews to the list — with the customer's permission — as they come in.

### 6. Photography

Every photo slot on the site currently renders a branded "photograph to follow"
panel rather than a gap or a stock image.
[`assets/img/photos/README.md`](assets/img/photos/README.md) lists the exact
filenames the build looks for, the shot each one needs, and how to prepare them.
Drop the files in and rebuild — no code changes, and no page breaks if a file is
missing.

Stock photography would be actively worse than the placeholders here. Visitors
choosing a local trade are looking for evidence that *this* firm did *that*
work, and library photos of anonymous engineers read as exactly what they are.

## SEO

Implemented:

- **Sitemap** — `sitemap.xml`, generated with per-page priority and change
  frequency, referenced from `robots.txt`.
- **robots.txt** — allows everything, blocks indexing of the contact form's
  query-string variants so they are not treated as duplicate pages.
- **Structured data** — `Plumber`/`LocalBusiness` on every page (address,
  geo, opening hours, areas served, Gas Safe and Companies House identifiers,
  service catalogue), plus `BreadcrumbList` on inner pages, `Service` on each
  service page, `FAQPage` on `/faq/`, `ContactPage` on `/contact/` and
  `WebSite` on the home page. 47 JSON-LD blocks, all machine-verified as valid
  JSON by the build.
- **Metadata** — a unique title and meta description per page, canonical URLs,
  Open Graph and Twitter card tags, and a generated 1200×630 social image.
- **Headings** — exactly one `<h1>` per page, no skipped levels, enforced by
  the build.
- **Internal linking** — every service page links to three related services or
  money pages; the grants, finance, areas and FAQ pages cross-link into the
  service pages; the footer carries the full site on every page.
- **`llms.txt`** — machine-readable business summary for language models.

Still to do, because it needs account access:

1. **Verify the domain in [Google Search Console](https://search.google.com/search-console)
   and submit `https://www.ecoheatplumbingandrenewables.co.uk/sitemap.xml`.**
   Repeat in [Bing Webmaster Tools](https://www.bing.com/webmasters).
2. **Create and verify a Google Business Profile.** For a local trade this
   outranks everything else on this list — most "plumber near me" traffic never
   reaches a website at all. Name, address and phone must match this site
   exactly, character for character.
3. **List on Checkatrade, TrustMark, MyBuilder and Yell**, with the same NAP
   details, and add the website URL to the Facebook page bio.

`SITE_URL` in `src/content.py` sets the canonical domain and must point at the
live domain before submitting anything to a search engine.

## Accessibility

Audited with axe-core (WCAG 2.1 A and AA) across all 16 content pages:
**zero violations**. Also verified in-browser:

- The site is fully navigable with JavaScript disabled — the menu and the FAQ
  are `<details>` disclosures, not scripted widgets.
- Colour contrast meets AA throughout. The logo's bright lime (`#8fdc3c`) is
  used only on dark backgrounds; a darker green (`#41780f`) carries text on
  light ones, because the brand lime only reaches 1.7:1 on white.
- Visible focus outlines, a skip link, real form labels, and `prefers-reduced-motion`
  honoured.
- Every image has descriptive alt text; the photo placeholders carry the alt
  text their eventual photograph will use.

## Deployment

`.github/workflows/build-check.yml` runs `build.py --check` on every push and
pull request.

`.github/workflows/deploy-pages.yml` publishes to GitHub Pages but is
**`workflow_dispatch` only, deliberately**. A repository has one Pages site, and
this repository already serves a different project from another branch — an
automatic trigger here would replace it. Run it by hand if a preview is wanted.

For production, this is a folder of static files: any host will serve it.
Point the document root at the repository root and enable HTTPS.

## Brand

Colours are sampled from the supplied logo rather than chosen independently:
charcoal `#141414`–`#222222` with lime `#9FEC5A`.

| Token | Value | Use |
| --- | --- | --- |
| `--ink` | `#14171a` | Page furniture, hero, footer |
| `--lime` | `#8fdc3c` | Accent and CTAs on dark |
| `--lime-dark` | `#41780f` | Links and accents on light (AA compliant) |
| `--amber` | `#f0a63c` | Emergency and urgency cues only |
| `--surface` | `#f6f7f4` | Alternating section background |

The amber is reserved exclusively for gas safety and emergency messaging so it
keeps its signal value — it should not be used decoratively.

`assets/img/ecoheat-logo.png` is the supplied logo with its dark background
keyed out to transparency so it sits cleanly on any surface; the favicon and
social image are derived from the same artwork.
